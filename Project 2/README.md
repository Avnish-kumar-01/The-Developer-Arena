# 🌐 Personal Portfolio Website

## Project Overview
This is my Personal Portfolio Website developed using **HTML5 and External CSS3**.  
The purpose of this project is to showcase my skills, education, and projects in a professional and responsive web format.

This project demonstrates my understanding of:
- Semantic HTML structure
- External CSS styling
- Responsive web design
- CSS Flexbox & Grid
- Hover effects and animations
- Modern UI design principles
